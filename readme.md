# Custom File Server v0.1.0

Simple ASP.NET Web API file server using PostgreSQL and MongoDB

### Prerequisites

- .NET 10 SDK
- npm
- Docker

### Quickstart

1. Clone the repository
2. Run docker
3. Run in the repo root
   - `npm i --prefix .\cfs.reactwebapp\`
   - `dotnet restore`
   - `dotnet run --project .\CFS.AspireApp\CFS.AspireApp.AppHost\`
